# Serato Playlist Automation — 快速指南

*专业 DJ 工具 — by SirvioDJ*

---

## 用途

将**客户播放列表**（文本、文件、YouTube/Spotify 链接）转换为活动可用的 **Serato crate**，并立即显示库中已有与缺失的曲目。

**典型节省时间：** 从数小时手动搜索缩短到几分钟引导式核对。

---

## 四步流程

### ① 配置音乐库

1. 设置**音乐文件夹**（如 `F:/`）
2. 点击**扫描音乐库** — 首次扫描可能需要几分钟；之后使用缓存更快
3. 确认绿色状态：*「音乐库：N 首曲目」*

### ② 加载客户播放列表

**客户播放列表**标签页：

- **从 URL 导入** — YouTube 或 Spotify
- **加载文件** — `.txt`、`.csv`、`.m3u`
- 或**直接粘贴**标题

推荐格式：`艺术家 - 标题`（每行一首）。

### ③ 匹配与审核

**与音乐库匹配** → **结果**标签页：

| 列 | 用途 |
|----|------|
| **Score %** | 找到曲目与请求的匹配程度 |
| **已找到** | 多个候选时的备选菜单 |
| **🔒 Lock** | 锁定 100% 匹配 |
| **Player** | 在应用内试听 |
| **选择** | 勾选要加入 crate 的曲目 |

使用**全选 ≥ X%** 批量勾选高于阈值的匹配。

### ④ 导出

- **创建 Serato Crate** — 生成 `.crate` 文件（需重启 Serato）
- **保存缺失...** — 待购买或待核实曲目的 `.txt` 列表

## 专业提示

- **Score ≥ 50%** 适合作为「全选」起点；正式活动可提高到 70–80%
- 在模糊行更换候选前，对确定匹配使用 **Lock**
- **重复**行（同一文件多行）显示为青色
- 结果/编辑标签页使用**全屏**处理长列表
- **删除**重复项后：关闭并重新打开 Serato
