# Serato Playlist Automation — Краткое руководство

*Профессиональный инструмент для DJ — by SirvioDJ*

---

## Зачем это нужно

Превращает **плейлист клиента** (текст, файл, URL YouTube/Spotify) в **crate Serato**, готовую к событию, сразу показывая, какие треки есть в библиотеке, а каких не хватает.

**Типичная экономия времени:** с часов ручного поиска до нескольких минут на проверку.

---

## Рабочий процесс в 4 шага

### ① Настройте библиотеку

1. Укажите **папку с музыкой** (напр. `F:/`)
2. Нажмите **Сканировать библиотеку** — первое сканирование может занять несколько минут; далее используется кэш
3. Проверьте зелёный статус: *«Библиотека: N треков»*

### ② Загрузите плейлист клиента

Вкладка **Плейлист клиента**:

- **Импорт по URL** — YouTube или Spotify
- **Загрузить файл** — `.txt`, `.csv`, `.m3u`
- Или **вставьте названия** напрямую

Рекомендуемый формат: `Исполнитель - Название` (по одному в строке).

### ③ Сопоставьте и проверьте

**Сопоставить с библиотекой** → вкладка **Результаты**:

| Столбец | Назначение |
|---------|------------|
| **Score %** | Насколько найденный трек соответствует запросу |
| **Найдено** | Меню с альтернативными кандидатами |
| **🔒 Lock** | Зафиксировать match на 100 % |
| **Player** | Прослушивание без выхода из приложения |
| **Выбор** | Отметить треки для crate |

**Отметить все ≥ X %** выбирает только matches выше порога.

### ④ Экспорт

- **Создать crate Serato** — создаёт `.crate` (перезапустите Serato)
- **Сохранить отсутствующие...** — `.txt` со списком треков для покупки или проверки

## Расширенные инструменты

### Обслуживание библиотеки (вкладка Редактирование)

| Функция | Когда использовать |
|---------|-------------------|
| **Очистить библиотеку** | Поиск слов или mojibake (`PreparÃ3`) |
| **Найти различия** | Треки на диске, но не в Serato |
| **Дубликаты** | Одинаковые название+исполнитель в нескольких копиях |
| **Обновить Serato** | Синхронизация метаданных (Serato закрыт) |

### Кнопка Краткое руководство

**Краткое руководство** всегда открывает этот документ.

### Алгоритм процентов

Кнопка в нижней панели подробно объясняет расчёт score.

---

## Советы профи

- **Score ≥ 50 %** — хорошая отправная точка; 70–80 % для формальных мероприятий
- Используйте **Lock** для надёжных matches перед сменой кандидата
- **Дубликаты** строк (один файл) подсвечиваются голубым
- **Полный экран** на вкладках Результаты/Редактирование для длинных плейлистов
- После **Удалить** дубликаты: закройте и снова откройте Serato
